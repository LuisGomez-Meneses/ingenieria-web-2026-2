Tienda con YOLO y ontologías

Este paquete contiene una tienda local funcional, el modelo YOLO11n, tres fotografías de prueba, la ontología y un editor de diagramas. La actividad principal consiste en usar el sistema y explicar su modelo.

Inicio en Windows

  1. Necesitas Python 3.10, 3.11 o 3.12 de 64 bits en un equipo Windows x64. Recomendado: Python 3.12. Puedes usar el instalador oficial de Python 3.12, opción Windows installer (64-bit). Durante la instalación marca Add python.exe to PATH.
  2. Extrae todo el ZIP en una carpeta local, por ejemplo Documentos\TiendaYOLO. No abras la aplicación desde dentro del ZIP.
  3. Haz doble clic en INICIAR.bat. La primera vez prepara .venv e instala las dependencias. Necesita internet y puede tardar varios minutos.
  4. Espera a que se abra http://127.0.0.1:8765. Si no se abre automáticamente, escribe esa dirección en Chrome, Edge o Firefox.
  5. Mantén abierta la ventana de la consola. Para detener, vuelve a esa ventana y pulsa Ctrl+C. Los pedidos se conservan.

Una vez instaladas las dependencias, la tienda y YOLO funcionan sin internet. No necesitas una GPU, CUDA, Node, Protégé ni instalar PyTorch para ejecutar este laboratorio. La primera ejecución del detector puede tardar más que las siguientes.

La primera demostración

  1. En Escáner YOLO, elige Cafetería con umbral 0,25.
  2. Observa la detección cup. La ontología la relaciona con Taza y la tienda propone taza01.
  3. Añade esa referencia, ajusta la cantidad a 2 y añade una botella. Confirma la compra con un nombre ficticio. El total debe ser $62.000 COP.
  4. En Pedidos, comprueba los detalles. En Ontología, consulta Recipiente y prueba el control de la relación de Taza.
  5. En Práctica en clase, abre el editor para completar tu diagrama. Guarda el JSON editable, el SVG y las evidencias de la ejecución.

Conservar o trasladar el trabajo

Descarga el JSON y el diagrama antes de cambiar de equipo. Para conservar toda la tienda, detén el servidor y copia la carpeta data y el archivo ontology/tienda.ttl. El carrito y el dibujo aún no exportado se guardan en el navegador. Si mueves la carpeta a otro equipo, no copies .venv: el iniciador debe crear el entorno allí.

Las descargas TTL y OWL de la sección Ontología contienen el esquema y los individuos actuales. El OWL se puede abrir en Protégé. El JSON del editor es un dibujo editable y no modifica automáticamente el archivo TTL.

Si aparece un problema

SituaciónQué hacer
No encuentra PythonInstala una de las versiones compatibles de 64 bits y vuelve a abrir INICIAR.bat.
No hay internet durante la instalaciónConéctate y repite INICIAR.bat. Los datos existentes se conservan.
Puerto 8765 ocupadoCierra la consola de una ejecución anterior. O abre una terminal en esta carpeta y ejecuta py -3.12 iniciar.py --port 8766.
No se carga la tiendaComprueba que la consola sigue abierta y usa la dirección local indicada. No abras index.html con doble clic.
DLL load failed en ONNX RuntimeComprueba que Python sea de 64 bits. La documentación oficial de ONNX Runtime indica el requisito de Visual C++ Runtime para Windows. Instala el runtime x64 desde Microsoft si falta y vuelve a intentar.
Modelo no encontradoComprueba que exista models/yolo11n.onnx y vuelve a extraer el ZIP completo si falta.
Una foto no produce el resultado esperadoPrueba Cafetería con umbral 0,25. Para fotos propias, mejora luz y encuadre. YOLO puede omitir o confundir objetos.

Para comprobar el paquete sin cambiar tus pedidos, abre DIAGNOSTICO.bat. Si todo funciona, termina con OK. En Linux o macOS compatibles puedes usar python3 iniciar.py y python3 iniciar.py --diagnostico.

Práctica académica local. La tienda registra pedidos de prueba, sin cobros ni envíos reales. Los datos no se transmiten a servicios externos durante el uso. La instalación inicial descarga dependencias de Python. Consulta FUENTES_Y_LICENCIAS.txt para la procedencia del modelo y las imágenes.
