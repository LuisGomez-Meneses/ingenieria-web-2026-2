# Sesión 01 — Fundamentos de Ingeniería Web

## Objetivo de aprendizaje

Comprender los conceptos fundamentales de la Ingeniería Web y el funcionamiento básico de la Web, identificando los principales componentes que intervienen en la comunicación entre un cliente y un servidor.

## Contenidos

Durante esta sesión se abordarán los siguientes temas:

1. Introducción al curso de Ingeniería Web.
2. ¿Qué es la Ingeniería Web?
3. Diferencia entre Internet y Web.
4. Arquitectura cliente-servidor.
5. Frontend y backend.
6. URL y nombres de dominio.
7. Introducción al DNS.
8. Protocolo HTTP.
9. Peticiones y respuestas HTTP.
10. Introducción a HTML.
11. Construcción de una primera página Web.

## Actividad práctica

Durante la sesión se construirá una primera página utilizando HTML con el propósito de comprender la relación entre un documento HTML y el navegador Web.

## Trabajo independiente

El estudiante desarrollará un pequeño sitio Web utilizando HTML como preparación para los siguientes contenidos del curso.
